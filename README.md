# Indie Film Collective

A four-page website for a community of independent filmmakers, built for Module 5. The site uses semantic HTML, one shared stylesheet, and a mobile-first layout: a single column on phones, a horizontal navigation bar and two-across cards from 600px, and a two-column page grid with a sidebar from 900px.

## Pages

- **index.html** — homepage, an introduction to the collective and links through to the three topic pages
- **screenings.html** — the monthly screening programme and what to expect on the night
- **workshops.html** — the current workshop series and how sessions run
- **collaborations.html** — the collaboration board and the roles most often requested

## Live site

https://lucamenasveta.github.io/5-Build/

## Built with

Semantic HTML, CSS Grid for the page layout, Flexbox for the navigation and the card row, and two media queries for the breakpoints. Every image has descriptive alt text and every internal link uses a relative path.
